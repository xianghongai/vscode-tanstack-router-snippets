# Changelog / 更新日志

## 1.0.2

- No snippet changes.
- The test suite now validates the snippet sources themselves — required fields, known `scope` language ids, balanced `${…}` placeholders and unique names — instead of parsing the expanded code. What a snippet expands to in a real file is settled in the editor, not here.

## 1.0.0

- Initial TanStack Router snippet collection for JavaScript, JSX, TypeScript and TSX.
- Cover router setup, file-based and code-based routes, navigation, search params, path params, data loading, router context and route boundaries.
- Include the TanStack Query integration seam, TanStack Start server functions and server routes, and cross-module recipes.
- 首个 TanStack Router 片段集，覆盖 JavaScript、JSX、TypeScript 与 TSX。
- 包含 router 装配、文件式与代码式路由、导航、search 参数、路径参数、数据加载、router context 与路由边界。
- 另含与 TanStack Query 的集成接缝、TanStack Start 的 server function 与 server route，以及跨模块组合场景。
